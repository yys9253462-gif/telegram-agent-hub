# 电报双智能体工作台

通过电报私聊控制 Claude Code 和 CodeBuddy Code。包括持久任务队列、停止任务、独立会话及共享摘要、模型搜索收藏、文件收发、语音转写确认、图片理解、生图及富文本流式回复。

## 环境

- Debian 12 或 Ubuntu 22.04 / 24.04，使用 systemd。
- x86_64 或 arm64；实际完整安装验收平台以发布说明为准。
- 建议至少 2 GiB 内存、5 GiB 空闲磁盘，可访问电报、模型网关和官方命令行下载源。
- 安装时使用 root 或可以 sudo 的账号；智能体以专用普通账号运行。
- 不需要开放入站端口，不需要域名或网页反代。

## 安装

私有仓库需要 GitHub 只读访问授权。发布交付的单行命令会在终端隐藏输入访问令牌，再下载固定提交并验证归档路径。令牌不进入命令参数、Git 远端和磁盘配置。不要把令牌拼进网址。

已经克隆仓库时，在目标服务器执行：

```sh
bash install.sh
```

安装器自动检查环境、安装系统依赖和启用的执行器，并交互询问：

1. 机器人令牌和唯一机主数字编号。
2. 聊天网关地址、密钥和默认模型。
3. 是否启用两种执行器及语音识别。
4. 可选生图接口地址、密钥和生图模型。
5. 可选远程主机、用户、端口、名称及独立核对的主机指纹。
6. 是否授权智能体免密管理员提权。

秘密输入隐藏显示。重跑安装器会继承配置，修改前备份；失败尝试恢复代码、配置和服务。新增系统软件、运行用户及模型缓存不自动卸载。

没有可交互终端时必须显式提供 `--yes --config /安全目录/config.json`。配置文件示例见 `install.example.json`，里面全部是假值。该文件仅供自动化使用，不是交互安装必需步骤。

```sh
bash install.sh --dry-run --yes --config /安全目录/config.json
bash install.sh --status
bash install.sh --uninstall
```

卸载只停用服务并撤销安装器添加的提权规则，保留用户文件、凭据和历史数据。重装可以继续使用。正式服务名称是 `telegram-agent-hub`。

## 数据与权限

- 程序：`/opt/telegram-agent-hub`
- 受限配置：`/etc/telegram-agent-hub`
- 运行用户：`agentbot`，工作目录：`/home/agentbot/tasks`
- 共享记忆与技能：`/home/agentbot/memory`
- 两种执行器原生会话分别保存；通过最近任务摘要交接，不是完整原生历史互通。
- 可选管理员权限覆盖安装机器；远程权限由远端授权决定。目标选择是行为指令，不是隔离沙箱。
- 生成的专用远程公钥必须由远端管理员加入授权；安装器不会绕过远端登录授权。

## 使用

发送 `/menu` 展开主菜单。直接输入任务进入队列；任务执行时仍可查看当前任务、停止和排队。停止不会回滚已执行操作。同步网络请求可能等待超时后才记录取消；已提交上游的生图请求不保证停止计费。

语音先转写，再按消息中的任务编号确认、修改或取消。普通文件上传只保存，不自动执行。发送文件仅允许任务目录内普通产物，排除常见密钥和凭据；规则扫描不能识别所有秘密。

生图使用独立的兼容 `/images/generations` 通道，默认要求内联图片返回。聊天目录可见不保证所有模型可调用或支持工具和图片。

定时巡检目前只有未启用的配置说明入口；没有自动巡检或告警。工具审计记录工具名称和任务结果，不提供完整文件差异或一键回滚。

## 记忆与技能迁移

仓库不包含个人记忆、日志、原生会话、SSH 私钥、模型配置或桌面登录态。基础共享记忆由安装器建立。需要迁移既有资料时，使用自己持有的私有素材包导入，不要把运行数据放进仓库。

## 验证

```sh
python3 test_project.py
python3 security_check.py
bash -n install.sh
```

`test_integration.py` 仅提供绑定回环地址的假消息接口，必须配合独立运行用户与独立服务名测试，不能替代真实端到端验收。测试模式禁止用于正式机器人。

官方执行器安装脚本使用已审阅的固定校验值。上游脚本改变时安装器会拒绝执行，应由维护者重新审阅并发布新版，不能直接关闭校验。
